# Nanquim

Navegador para Windows com o motor do Chrome e visual próprio de tinta e papel.

## Baixar

Pegue o instalador mais recente em [Releases](https://github.com/xpsy6/nanquim/releases/latest) (arquivo `Nanquim-Setup-x.x.x.exe`).

Depois de instalado, o Nanquim se atualiza sozinho: procura versão nova ao abrir e a cada 2 horas, baixa por trás e instala quando você fecha o navegador.

## O que ele tem

- Abas, favoritos, histórico, downloads, janela anônima e restauração de sessão
- Bloqueador de anúncios e rastreadores, inclusive no YouTube
- Painéis laterais com WhatsApp, Instagram, Discord, Spotify e outros, abrindo por cima da página
- Print com editor (Ctrl+Shift+5): área, tela visível ou página inteira, com caneta, seta, texto e desfoque
- Temas Tinta (escuro) e Papel (claro), com as cores que você escolher
- Medidor de memória e abas que dormem para economizar RAM
